# Scalp AI Agent

두피 이미지를 분석하여 두피 상태를 파악하고,
사용자에게 적합한 관리 제품을 추천하는 AI Agent 프로젝트입니다.

## 주요 기능

- 두피 이미지 촬영
- 이미지 품질 확인
- AI 기반 두피 상태 분석
- 사용자 문진
- 맞춤형 제품 추천
- 분석 결과 저장 및 관리
