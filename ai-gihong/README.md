# AI 파트 — 상품 추천 / LLM 리포트

담당: 임기홍

두피 분석 모델의 추론 결과를 받아 증상에 맞는 헤어케어 상품을 추천하는 모듈.
LLM 리포트 생성 완성 후 이 모듈과 함께 하나의 API로 묶음.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `recommend.py` | 증상 정보 → 상품 추천. 성분·유사도·별점 종합 후 상위 5개 반환 |
| `ingredient_scores.py` | 전성분 텍스트 → 6개 증상별 성분 점수 |
| `prepare_data.py` | 수집 원본 CSV → 정제된 상품 데이터셋 |
| `data/products.csv` | 상품 데이터셋 |
| `requirements.txt` | 필요 패키지 목록 |

## 입력 형식

두피 분석 모델의 추론 결과(예상)를 수신.

```json
{
  "status": "success",
  "symptoms": {
    "micro_keratin":       { "level": 2, "probs": [0.1, 0.2, 0.6, 0.1] },
    "excess_sebum":        { "level": 0, "probs": [0.8, 0.1, 0.1, 0.0] },
    "follicular_erythema": { "level": 1, "probs": [0.3, 0.5, 0.2, 0.0] },
    "follicular_pustule":  { "level": 0, "probs": [0.9, 0.1, 0.0, 0.0] },
    "dandruff":            { "level": 3, "probs": [0.0, 0.1, 0.2, 0.7] },
    "hair_loss":           { "level": 1, "probs": [0.2, 0.6, 0.2, 0.0] }
  }
}
```

- `level` : 0(양호) ~ 3(중증)
- 전 증상 0일 경우 자극이 적은 데일리 제품 추천

## 출력 형식 (예상)

```json
[
  {
    "name": "상품명",
    "price": 19900,
    "rating": 4.8,
    "reviews": 12043,
    "category": "shampoo",
    "image": "https://...",
    "link": "https://...",
    "reason": "비듬, 각질 관리에 맞는 제품 (징크피리치온, 살리실릭애씨드 함유)"
  }
]
```

## 추천 점수 구성

```
점수 = 성분 점수 0.5 + 임베딩 유사도 0.3 + 보정 별점 0.2
```

활성 증상이 복수일 경우 심각도의 제곱으로 가중.
level 3은 가중치 9, level 1은 1이므로 심각한 증상이 추천을 주도함.

### 1. 성분 점수 (0.5)

전성분 텍스트에서 근거가 확인된 성분을 탐색해 증상별 점수 부여.
점수 크기는 근거 수준에 따라 4단계로 구분.

| 점수 | 기준 |
|---|---|
| 1.0 | 식약처 고시 조합 충족 / 사람 대상 비교 임상에서 기준 성분으로 사용된 성분 |
| 0.6 | 사람 대상 임상 1건 이상 (단, 농도·부위가 제품과 상이) |
| 0.5 | 식약처 고시 조합의 일부만 포함 / 세포·체외 연구 수준 |
| 0.3 | 주 효과가 아닌 보조 효과 / 두피 외 부위 연구 |

- 동일 증상에 복수 성분이 해당될 경우 **최댓값 + 성분 개수당 0.1** 가산
- 가산 미적용 시 최고점 상품 간 동점이 대량 발생하여 변별 불가
- 성분표 내 **위치는 가중치로 사용하지 않음**
  - 화장품법 시행규칙 별표4에 따라 1% 이하 성분은 순서 무관하게 표시 가능
  - 표시 위치가 함량을 반영하지 않음
- 성분별 출처는 `성분점수_근거자료.md`에 링크와 함께 정리

### 2. 임베딩 유사도 (0.3)

한국어 문장 임베딩 모델(`jhgan/ko-sroberta-multitask`)로
증상별 검색 문장과 상품명·상품 설명 간 코사인 유사도 산출.

- 성분 점수가 포착하지 못하는 영역을 보완
- 유효 성분이 식물 추출물이라 성분 규칙에 미해당인 제품도
  상품명에 "비듬", "스케일링" 등이 포함되면 여기서 포착됨
- 전성분은 임베딩 문장에서 제외
  - 상품마다 성분이 40~60개씩 중복되어 문장이 서로 유사해짐
  - 변별력이 오히려 저하됨

### 3. 보정 별점 (0.2)

리뷰 수가 적은 상품의 고평점을 그대로 신뢰하지 않도록 가중 평점 적용.

```
WR = (v / (v + m)) × R + (m / (v + m)) × C
```

| 기호 | 의미 |
|---|---|
| `v` | 해당 상품 리뷰 수 |
| `R` | 해당 상품 별점 |
| `C` | 전체 평균 별점 |
| `m` | 기준 리뷰 수 |

### 카테고리 보정

제품 목적이 증상과 직접 부합할 경우 성분 점수에 가산.
성분만으로는 "각질 제거용 스케일러"와 "살리실릭애씨드가 소량 포함된 일반 샴푸"가 구분되지 않음.

| 카테고리 | 대상 증상 |
|---|---|
| 스케일러 | 미세각질, 피지과다 |
| 토닉 | 탈모 |

## 상품 데이터셋

올리브영·화해에서 수작업 수집.

- 외부 쇼핑 API 사용 불가
  - 네이버 쇼핑 검색 API 종료
  - 쿠팡 파트너스 승인 거절
  - 11번가 판매자 전용 제한
- 각 사이트 robots.txt가 자동 수집을 차단하여 크롤러 대신 북마클릿 사용
  - 이미 열린 페이지의 렌더링된 내용만 읽어오는 방식
- 수집 데이터는 과제 시연 목적으로만 사용

| 카테고리 | 개수 |
|---|---|
| 샴푸 | 83 |
| 토닉 | 26 |
| 트리트먼트 | 20 |
| 스케일러 | 17 |
| **합계** | **146** |

**상품은 지속적으로 추가 예정.**
추가 수집 시 `prepare_data.py`로 정제 후 `data/products.csv`에 병합.

## 실행

가상 환경에서 실행

```bash
python -m venv venv
venv\Scripts\activate          # macOS / Linux: source venv/bin/activate
pip install -r requirements.txt
python recommend.py
```

- `recommend.py` 직접 실행 시 터미널에서 증상 심각도를 입력받아 추천 결과 출력
- `sentence-transformers`가 `torch`를 함께 설치하므로 최초 설치에 시간 소요

상품 데이터셋 신규 수집 시 정제 스크립트 선행.

```bash
python prepare_data.py data/수집한파일.csv
```
