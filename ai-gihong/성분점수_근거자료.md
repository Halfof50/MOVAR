# 성분 점수표 근거 자료

`ingredient_scores.py`의 성분–증상 연결과 점수 크기에 대한 출처 정리.

## 점수 부여 원칙

| 점수 | 기준 |
|---|---|
| 1.0 | 식약처 고시 조합 충족 / 사람 대상 비교 임상에서 기준 성분으로 사용된 성분 |
| 0.6 | 사람 대상 임상 1건 이상 (단, 농도·부위가 실제 제품과 상이) |
| 0.5 | 고시 조합의 일부만 포함 / 세포·체외 연구 수준 / 함량이 낮을 가능성이 큰 성분 |
| 0.3 | 주 효과가 아닌 보조 효과 / 두피 외 부위 연구 |

- 동일 증상에 복수 성분이 해당될 경우 **최댓값 + 성분 개수당 0.1** 가산
  - 가산 미적용 시 최고점 상품 간 동점이 대량 발생하여 순위 변별 불가
  - 가산 결과가 1.0을 초과할 수 있으며, 증상별 정규화는 `recommend.py`에서 처리
- 성분표 **위치는 가중치로 사용하지 않음**
  - 화장품법 시행규칙상 1% 이하 성분은 순서와 무관하게 표시 가능
  - 탈모 고시 성분(0.2~0.3%)처럼 농도가 낮은 핵심 성분의 경우 위치가 함량을 반영하지 않음

## 성분별 점수와 근거

| 성분 | 증상 점수 | 근거 |
|---|---|---|
| 징크피리치온 | 비듬 1.0, 탈모 0.5 | S2, S3, S1 |
| 피록톤올아민 | 비듬 1.0 | S2, S3 |
| 클림바졸 | 비듬 1.0 | S3 |
| 티트리 | 비듬 0.6, 피지 0.3 | S4 |
| 살리실릭애씨드 | 각질 0.5, 비듬 0.3, 탈모 0.5 | S5, S9, S1 |
| 유레아 | 각질 0.5 | S12, S13 |
| 글라이콜릭애씨드 | 각질 0.3 | S13, S14 |
| 락틱애씨드 | 각질 0.3 | S14, S15 |
| 나이아신아마이드 | 피지 0.5, 탈모 0.5 | S6, S1 |
| 병풀(마데카소사이드 등) | 모낭사이홍반 0.5, 모낭홍반농포 0.5 | S7 |
| 다이포타슘글리시리제이트 | 모낭사이홍반 0.3, 모낭홍반농포 0.3 | S11 |
| 카페인 | 탈모 0.5 | S8 |
| 덱스판테놀 | 탈모 0.5, 모낭사이홍반 0.3 | S1, S10 |
| 비오틴 | 탈모 0.5 | S1 |
| 멘톨 | 탈모 0.5 | S1 |

**탈모 고시 조합 충족 시 탈모 1.0**
- 조합 A: 덱스판테놀 + 살리실릭애씨드 + 엘-멘톨
- 조합 B: 나이아신아마이드 + 덱스판테놀 + 비오틴 + 징크피리치온

**표기 변형 처리**
- 동일 성분의 표기 차이는 `ALIASES`에서 대표 이름으로 통합
  - 예: 엘-멘톨 / L-멘톨 / 멘톨, 살리실릭애씨드 / 소듐살리실레이트 / 살리실산
- 이름이 유사하나 작용이 다른 성분은 매칭 전 제거 (`EXCLUDE`)
  - 하이드록시에틸우레아: 보습제이며 각질용해 작용 없음. 유레아로 오인되지 않도록 제외

## 근거 자료

**S0. 전성분 표시 순서 규정 (화장품법 시행규칙 별표4)**
함량이 많은 것부터 표시하되, 1% 이하 성분·착향제·착색제는 순서에 상관없이 표시 가능
- 대한화장품협회 법령 안내: https://kcia.or.kr/cid/cs/law.php

**S1. 식약처 탈모 증상 완화 기능성 고시 성분**
덱스판테놀 0.2%·살리실릭애씨드 0.25%·엘-멘톨 0.3% 조합, 또는 나이아신아마이드 0.3%·덱스판테놀 0.5%·비오틴 0.06%·징크피리치온액(50%) 2% 조합
- 헬스경향 (2021.12.13): https://www.k-health.com/news/articleView.html?idxno=57042
- 코스모닝, 기능성화장품 심사 규정 개정 (2020.10.11): https://www.cosmorning.com/news/article.html?no=38072
- 식약처 공고 제2020-435호 원문 (WTO 통보문): https://members.wto.org/crnattachments/2020/TBT/KOR/20_6339_00_x.pdf

**S2. 피록톤올아민+살리실릭애씨드 vs 징크피리치온 비듬 비교 임상**
두 샴푸 모두 비듬을 크게 감소시킴 (이중맹검, 19명)
- PubMed 18503415: https://pubmed.ncbi.nlm.nih.gov/18503415/

**S3. 피록톤올아민+클림바졸 vs 징크피리치온 비듬 비교 임상**
0.5% 피록톤올아민 + 0.45% 클림바졸이 1% 징크피리치온과 비슷한 항진균 효과
- PubMed 21272039: https://pubmed.ncbi.nlm.nih.gov/21272039/

**S4. 5% 티트리 오일 샴푸 비듬 임상 (JAAD 2002)**
126명 대상, 위약 대비 비듬 중증도 점수 41% vs 11% 개선. 가려움·기름짐 자가평가도 개선
- PubMed 12451368: https://pubmed.ncbi.nlm.nih.gov/12451368/
- 0.6으로 둔 이유: 연구 농도(5%)가 시판 제품보다 높을 가능성이 큼

**S5. 살리실릭애씨드의 각질용해 작용**
각질세포 간 결합을 풀어 각질 제거를 도움. 단독으로는 비듬에 불충분해 항진균 성분과 병용
- Typology: https://us.typology.com/library/which-active-ingredients-can-act-against-dandruff

**S6. 2% 나이아신아마이드 피지 감소 임상 (J Cosmet Laser Ther 2006)**
일본인 대상 연구에서 피지 분비율 유의하게 감소
- PubMed 16766489: https://pubmed.ncbi.nlm.nih.gov/16766489/
- 0.5로 둔 이유: 얼굴 대상 연구이며, 서양인 대상에서는 피지 분비율 감소가 유의하지 않았음

**S7. 병풀(마데카소사이드) 항염 작용**
마데카소사이드가 염증성 사이토카인 IL-1β 억제
- PubMed 30452312: https://pubmed.ncbi.nlm.nih.gov/30452312/
- 병풀 추출물 항염·면역조절 (PMC): https://pmc.ncbi.nlm.nih.gov/articles/PMC11643272/
- 0.5로 둔 이유: 세포 수준 연구이며 두피 대상 임상 아님

**S8. 카페인 모낭 성장 촉진 (Int J Dermatol 2007)**
남성형 탈모 환자 모낭 배양에서 테스토스테론의 성장 억제를 카페인이 상쇄
- PubMed 17214716: https://pubmed.ncbi.nlm.nih.gov/17214716/
- 0.5로 둔 이유: 체외(in vitro) 연구

**S9. 미국 OTC 비듬 성분 기준**
샴푸 기준 징크피리치온 0.3~2%, 살리실릭애씨드 1.8~3%
- Euro Cosmetics Magazine: https://www.eurocosmetics-mag.com/advancing-salicylic-acid-baseddandruff-control/
- 살리실릭애씨드 각질 점수를 0.5로 제한한 이유: 탈모 고시 조합 농도(0.25%)가 이 기준보다 훨씬 낮음

**S10. 덱스판테놀 피부 홍반 감소 무작위 대조 연구**
SLS로 자극을 유발한 피부에서 덱스판테놀 적용 시 홍반 감소
- PubMed 19753737: https://pubmed.ncbi.nlm.nih.gov/19753737/
- 0.3으로 둔 이유: 주 효과가 아닌 보조 효과이며, 두피가 아닌 피부 대상 연구

**S11. 다이포타슘글리시리제이트(감초 유래) 함유 보습제 아토피 피부염 임상**
글리시리진 유도체 함유 제형에서 홍반·소양 개선
- PMC12302091: https://pmc.ncbi.nlm.nih.gov/articles/PMC12302091/
- 0.3으로 둔 이유: 두피가 아닌 피부 대상 연구이며, 단일 성분이 아닌 제형 단위 평가

**S12. 고농도 유레아 각질용해 작용 임상 근거 리뷰 (Int J Clin Pract 2020)**
유레아가 두피 각질을 무르게 해 제거를 용이하게 함. 비듬·지루성 피부염 항목 포함
- 원문: https://onlinelibrary.wiley.com/doi/10.1111/ijcp.13740
- 전문 PDF: https://cris.unibo.it/bitstream/11585/792996/1/urea%202020%20.pdf
- 0.5로 둔 이유
  - 두피가 대상 부위인 근거가 존재하나, 각질용해 효과 확인 농도가 40~50%로 화장품 함량과 차이가 큼
  - 근거가 무작위 대조 연구가 아닌 개방형·관찰 연구 중심

**S13. 유레아+글라이콜릭애씨드+살리실릭애씨드 샴푸 두피 각질 임상 (Cogent Medicine 2018)**
두꺼운 각질·홍반·비듬 두피 대상, 각질 및 가려움 개선
- 원문: https://www.tandfonline.com/doi/full/10.1080/2331205X.2018.1475095
- 초록(DOAJ): https://doaj.org/article/20c991180cdf4e81a8fb6c8ae3fadda5
- 글라이콜릭애씨드를 0.3으로 제한한 이유
  - 개방형·대조군 없음·10명·3성분 조합 연구로 단독 기여 분리 불가

**S14. AHA 각질박리 작용 (J Dermatol 2006)**
알파하이드록시산의 각질층 박리 작용 및 화학적 피부박리 근거
- PubMed 16469079: https://pubmed.ncbi.nlm.nih.gov/16469079/
- 0.3으로 둔 이유: 두피가 아닌 피부 대상 연구

**S15. 락틱애씨드 각질층 지질·배리어 체외 연구 (Arch Dermatol Res 1996)**
락틱애씨드 이성질체가 각질형성세포 세라마이드 합성 및 각질층 지질 수준에 영향
- PubMed 8818186: https://pubmed.ncbi.nlm.nih.gov/8818186/
- 0.3으로 둔 이유
  - 체외 연구이며 두피 대상 아님
  - 락틱애씨드는 화장품에서 pH 조절제로도 사용되어, 함유 사실만으로 각질 목적을 단정할 수 없음

## 별점 보정

**IMDb 가중 평점 (베이지안 추정)**
```
WR = (v ÷ (v + m)) × R + (m ÷ (v + m)) × C
```
- v: 리뷰 수, R: 제품 평점, m: 기준 리뷰 수, C: 전체 평균 평점
- IMDb 공식 도움말: https://help.imdb.com/article/imdb/track-movies-tv/ratings-faq/G67Y87TFYYP6TWAV
- 리뷰 수가 적은 상품의 고평점을 전체 평균 쪽으로 끌어당겨 보정

| 멘톨의 피지 조절 효과 | 근거 미확보. 멘톨은 탈모 고시 조합 성분으로만 반영 |
